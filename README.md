## 🧩 Arquitectura del proyecto

La presentación web utiliza una estructura basada en HTML, CSS y JavaScript.

El proyecto organiza sus recursos y contenidos en directorios independientes, incluyendo:

- `css/`: estilos y presentación visual.
- `js/`: lógica y funcionalidades de la aplicación.
- `data/`: información estructurada en JSON.
- `cv/`: recursos relacionados con la presentación del currículum.
- `img/`: recursos gráficos.

La aplicación utiliza JavaScript para cargar información estructurada y construir dinámicamente su contenido.
